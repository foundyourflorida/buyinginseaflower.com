# Deploying buyinginseaflower.com

The site is plain static files in `docs/`. Any static host works; the zero-cost path is GitHub Pages under the `foundyourflorida` GitHub account (already logged in via `gh` on this Mac).

## One-time setup (GitHub Pages)

```bash
cd /Users/trentonmiller/buyinginseaflower
git init -b main
git add -A && git commit -m "Buying in SeaFlower: initial site"
gh repo create buyinginseaflower.com --public --source=. --push
gh api -X POST repos/foundyourflorida/buyinginseaflower.com/pages -f build_type=legacy -f 'source[branch]=main' -f 'source[path]=/docs'
gh api -X PUT repos/foundyourflorida/buyinginseaflower.com/pages -f cname=buyinginseaflower.com -F https_enforced=true
```

(The repository must be public for Pages on a free account; the site is public anyway.)

## DNS at Squarespace (the domain's current registrar)

Squarespace Domains → buyinginseaflower.com → DNS settings. Remove the Squarespace "Coming Soon" records and add:

| Type | Host | Value |
|---|---|---|
| A | @ | 185.199.108.153 |
| A | @ | 185.199.109.153 |
| A | @ | 185.199.110.153 |
| A | @ | 185.199.111.153 |
| CNAME | www | foundyourflorida.github.io |

Wait for propagation (minutes to a few hours), then in the repo's Settings → Pages confirm the custom domain shows a green check and "Enforce HTTPS" is on. `docs/CNAME` is generated by the build so the custom domain survives redeploys.

## Every update

```bash
python3 build.py && git add -A && git commit -m "Update" && git push
```

Pages rebuilds in about a minute.

## After launch

- Google Search Console: add the property, submit `https://buyinginseaflower.com/sitemap.xml`.
- Bing Webmaster Tools: same (ChatGPT search reads Bing's index).
- Google Business Profile: add buyinginseaflower.com as a secondary link; keep name/phone identical to foundyourflorida.com.
- Link from foundyourflorida.com's SeaFlower community page to this site.
- Set `SITE["form_endpoint"]` and test one lead end to end.
